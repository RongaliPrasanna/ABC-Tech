# ABC Tech – ITSM Incident Priority Prediction

## Project Overview
Developed a Machine Learning-based IT Service Management (ITSM) pipeline to automate incident priority classification and identify high-priority incidents requiring escalation.

## Technologies Used
- **Programming:** Python
- **Libraries:** Pandas, NumPy, Scikit-learn
- **Machine Learning:** XGBoost, SMOTE
- **Database:** MySQL
- **API:** FastAPI
- **Preprocessing:** Data Cleaning, Feature Engineering, StandardScaler

## Key Features
- Automated IT incident priority prediction.
- Data cleaning and preprocessing.
- Handling imbalanced datasets using SMOTE.
- Incident classification using XGBoost.
- MySQL database integration.
- REST API development using FastAPI.
- Runbook text processing and chunking.

## Project Workflow
1. Data Collection
2. Data Cleaning and Preprocessing
3. Feature Engineering
4. Class Imbalance Handling
5. Model Training and Prediction
6. API Development

## Business Impact
- Reduces manual incident classification.
- Supports faster incident prioritization.
- Helps identify critical incidents.
- Improves IT service management efficiency.
